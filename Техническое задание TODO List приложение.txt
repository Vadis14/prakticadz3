2. Детальные спецификации
2.1. Модель данных задачи (Task)
typescript
interface Task {
  id number  string;
  title string;
  description string;
  completed boolean;
  createdAt string;  ISO date string
  updatedAt string;  ISO date string
  isUpdated boolean;  флаг обновления
}
2.2. API endpoints (JSON-server)
text
GET    tasks          - получить все задачи
GET    tasksid      - получить задачу по ID
POST   tasks          - создать новую задачу
PUT    tasksid      - обновить задачу
PATCH  tasksid      - частично обновить задачу
DELETE tasksid      - удалить задачу
2.3. Компоненты интерфейса
2.3.1. Основные компоненты
•	TaskForm Форма созданияредактирования задачи
•	TaskList Список задач
•	TaskItem Элемент списка задач
•	Loader Компонент загрузки
•	FilterBar Панель фильтрации и поиска
2.3.2. Форма задачи
jsx
 Поля
- Input Заголовок (required)
- Textarea Описание
- Checkbox Выполнено
- Button СохранитьОбновить
- Button Отмена (при редактировании)
2.3.3. Элемент списка задач
jsx
 Отображает
- Чекбокс выполнения
- Заголовок (зачеркнутый если выполнено)
- Описание (обрезанное с кнопкой показать больше)
- Дата создания
- Дата обновления (если была изменена) с пометкой updated
- Кнопки Редактировать, Удалить
2.4. Состояния загрузки
2.4.1. Типы лоадеров
•	Global loader При первоначальной загрузке приложения
•	Inline loader Для отдельных операций (удаление, обновление)
•	Button loader В кнопках отправки форм
•	Skeleton loader Для списка задач при загрузке
2.5. Обработка ошибок
